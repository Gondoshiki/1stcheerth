# Gallery (แกลเลอรีส่วนตัว)

แอพ Android แสดงโฟลเดอร์และรูปในเครื่องอัตโนมัติ หน้าตาแนว Right Gallery
เพิ่มแท็กให้แต่ละโฟลเดอร์และค้นหาตามแท็กได้ โทนมืด ไทย/อังกฤษ เก็บข้อมูลแท็กในเครื่องอย่างเดียว

## หน้าจอและความสามารถ
- **หน้าแรก = โฟลเดอร์ในเครื่อง** กริดรูปปกมุมมน ชื่อโฟลเดอร์ จำนวนรายการ และแท็ก
  - ช่องค้นหาด้านบน ค้นด้วยชื่อโฟลเดอร์หรือแท็ก
  - ชิปแท็กใต้ช่องค้นหา แตะเพื่อกรอง เลือกได้หลายแท็ก (ต้องมีครบทุกแท็กที่เลือก)
  - ไอคอนรูป = รูปทั้งหมด (แบ่งหัวข้อตามวัน ค้นด้วยชื่อรูป/ชื่อโฟลเดอร์/แท็กได้)
  - ไอคอนเรียงลำดับ = กล่อง "เรียงตาม": ชื่อ / เส้นทาง / ขนาด / จำนวนรายการ / แก้ไขล่าสุด / วันที่ถ่าย / สุ่ม + น้อยไปมาก/มากไปน้อย
    - ติ๊ก "เรียงตัวเลขในชื่อตามค่าจริง" = 1, 2, 10 (ไม่ใช่ 1, 10, 2)
    - แอพจำค่าที่ตั้งไว้ และใช้กับทุกโฟลเดอร์ ถ้าอยากให้โฟลเดอร์ไหนเรียงต่างออกไป ให้เปิดโฟลเดอร์นั้นแล้วติ๊ก "ใช้กับโฟลเดอร์นี้เท่านั้น" ก่อนกดตกลง (ถ้าไม่ติ๊ก แล้วกดตกลงในโฟลเดอร์นั้น จะกลับมาใช้ค่ากลางของทุกโฟลเดอร์)
  - เมนู ⋮ = เปลี่ยนรูปแบบการแสดงผล (ตาราง/รายการ), จำนวนคอลัมน์ (1-5), จัดการแท็ก, สลับภาษา
- **ใส่แท็กให้โฟลเดอร์**: กดไอคอนแท็กบนการ์ดโฟลเดอร์ (หรือกดค้างที่การ์ด หรือไอคอนแท็กในหน้าโฟลเดอร์)
- **หน้าโฟลเดอร์**: รูปในโฟลเดอร์ ค้นด้วยชื่อ เรียงลำดับ กดค้างเพื่อเลือกหลายรูป แชร์ ลบ
- **ดูรูป**: ปัดซ้าย/ขวา ถ่างนิ้วหรือแตะสองครั้งเพื่อซูม แตะครั้งเดียวเพื่อซ่อนแถบ แชร์/ลบได้
- ลบรูปจะลบจากเครื่องจริง ระบบ Android ถามยืนยันก่อนเสมอ (ใช้ได้บน Android 11 ขึ้นไป)

ยังไม่มี: วิดีโอ, โฟลเดอร์ซ่อน/ยกเว้น, สร้างโฟลเดอร์ใหม่, แก้ไขรูป, ถังขยะ, เรียงแบบกำหนดเอง (Custom)

หมายเหตุ: แท็กผูกกับโฟลเดอร์ด้วยรหัสโฟลเดอร์ของระบบ ถ้าย้ายหรือเปลี่ยนชื่อโฟลเดอร์ในเครื่อง แท็กของโฟลเดอร์นั้นจะต้องใส่ใหม่

## วิธีสร้างไฟล์ APK

### วิธีที่ 1: GitHub Actions (ไม่ต้องติดตั้งอะไรเลย)
1. อัปโหลดไฟล์ทั้งหมดขึ้น repository (ต้องมีไฟล์ `.github/workflows/build-apk.yml` ด้วย)
2. แท็บ **Actions** > **Build APK** > **Run workflow**
3. รอ 5-10 นาที เปิดรันที่เสร็จ ดาวน์โหลด `gallery-debug-apk` ที่ส่วน Artifacts ด้านล่างสุด
4. แตกซิปจะได้ `app-debug.apk` ส่งเข้ามือถือแล้วติดตั้ง

### วิธีที่ 2: Android Studio
เปิดโฟลเดอร์นี้ รอ Gradle sync แล้ว Build > Build APK(s)
ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## แก้ไขเพิ่มเติม
- ชื่อ package: `app/build.gradle.kts` (`applicationId`, `namespace`)
- ชื่อแอพ/ข้อความ: `app/src/main/res/values/strings.xml` และ `values-th/strings.xml`
- สี: `app/src/main/java/com/example/gallery/ui/Theme.kt`

## โครงสร้างโค้ด
- `data/DeviceMedia.kt` อ่านรูปจาก MediaStore
- `data/` ฐานข้อมูล Room เก็บแท็กและการติดแท็กโฟลเดอร์
- `GalleryViewModel.kt` ตรรกะค้นหา/กรอง/เรียงลำดับ
- `ui/` หน้าจอ Compose: `FoldersScreen`, `PhotosScreen` (รูปทั้งหมด), `FolderScreen`, `ViewerScreen`
